# Security and moderation

## Reporting a vulnerability

This repository contains only documentation. If you find a security problem in the comment
setup, report it privately through
[GitHub security advisories](https://github.com/diogocouto18/dev-hub-comments/security/advisories/new)
rather than a public discussion or issue.

## Reporting abusive or spam comments

Use "Report content" on the comment in GitHub, or contact the owner. Comments that break the
[Code of Conduct](CODE_OF_CONDUCT.md) are deleted or hidden, and repeat offenders are blocked.

## Why visitors cannot create threads

Discussions are created only by the giscus app, in the `Announcements` category, which is
restricted to maintainers and apps. See the README for the giscus configuration.
